# Glossary

## Glossary

### AI summary

A generated status briefing. It summarizes available DevControl2 data.

### Assist

Home Assistant's conversational assistant. It answers questions using configured Home Assistant data.

### Card

A dashboard component that displays information or controls. A card can show one or many entities.

### Cards and entities

A card is the visible dashboard element. An entity is the underlying Home Assistant data point or control.

For example, one EcoFlow card can show battery level, input power, and output power. Each value is a separate entity.

### DevControl2

The custom Home Assistant-based control system for Bombol.Space.

### Entity

A single Home Assistant data point or control. Examples include a battery level, door state, or switch.

### EcoFlow

The integrated portable power-station system. DevControl2 shows its available battery and power data.

### Home Assistant

The home-automation platform that powers DevControl2.

### Tapo

The integrated security-device system. It includes supported hub, door, and motion sensors.
