# Understand alerts

When an alert is triggered, immediate action may be required to protect the equipment.

**Emergency Procedures**

If an alert is active, follow the specific instructions displayed in the notification. In most critical scenarios, this requires parking the telescope so we can close the roof.

Primary Alert Triggers:

* Weather Hazards: Detection of incoming rain or moisture.
* Wind Protection: Sustained wind speeds or gusts exceeding safety limits.
* Security Breach: Unauthorized person detected within the perimeter.
* System Criticality: Hardware malfunctions or communication failures requiring manual intervention.
