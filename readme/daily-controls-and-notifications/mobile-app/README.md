# Mobile app

## Mobile app

Use the Home Assistant Companion app to access DevControl2 from your phone.

The app provides the same dashboards and controls available in your browser.

### Install the app

1. Install **Home Assistant** from the Apple App Store or Google Play.
2. Open the app and select **Enter address manually**.
3. Enter the DevControl2 address and sign in with your Home Assistant account.

{% hint style="info" %}
Use the same account that you use for DevControl2 in your browser.
{% endhint %}

### Use DevControl2 on your phone

After you sign in, open a dashboard from the sidebar.

You can view device status and use controls that your account can access. Dashboard layouts can differ on smaller screens.

### Keep the app connected

Allow the app to use network access in your phone settings.

Enable notifications if you want DevControl2 alerts on your phone. See [Phone notifications](phone-notifications.md).
