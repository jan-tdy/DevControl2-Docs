# AI features

## AI features

DevControl2 offers two AI features: **AI summary** and **Home Assistant Assist**.

### What each feature does

* **AI summary** highlights current conditions, energy status, and recent events.
* **Home Assistant Assist** answers questions about available Home Assistant data.
* **Camera AI summary** describes recent camera information when configured.

AI output is informational. Always verify equipment status before acting.

### Choose a feature

Use **AI summary** for a quick dashboard briefing.

Use **Assist** for a specific question about current conditions or device states.

{% hint style="warning" %}
Assist does not replace safety procedures. It cannot safely operate roofs or other safety-critical equipment.
{% endhint %}

See [Use Assist](use-assist/) for supported questions and limits.
