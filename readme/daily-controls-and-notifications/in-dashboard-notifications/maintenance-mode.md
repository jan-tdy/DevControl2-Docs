# Maintenance mode

## Maintenance mode

Maintenance mode indicates that DevControl2 is undergoing maintenance.

The system may restart unexpectedly. Dashboard card layouts may also change.

### When maintenance mode is active

A yellow in-dashboard notification appears at the top of the **Conditions** tab.

See [In-dashboard notifications](./) for more information.

### What you should do

You can continue using DevControl2 during maintenance.

* Expect a possible restart while you work.
* Not all cards may functions while staff improves them or adds new features.

{% hint style="info" %}
Maintenance mode was introduced in release `2026.07_1.1`.
{% endhint %}
